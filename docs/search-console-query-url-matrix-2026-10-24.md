# Query-naar-URL-matrix

Bron: Google Search Console, Prestaties in zoekresultaten, web, 3 maanden.
Periode: 25 juli 2026 t/m 24 oktober 2026. Laatste update tijdens export: 4 uur geleden.

De matrix hieronder bevat de belangrijkste niet-merkzoekopdrachten uit de eerste querypagina. `concurrerende URL's` zijn URL's die voor dezelfde zoekintentie zichtbaar zijn; ankers binnen dezelfde pagina zijn niet als aparte URL opgenomen.
